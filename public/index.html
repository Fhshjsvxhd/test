Everything a tracker needs. Nothing it doesn't.

The essentials of tracking platforms and cloakers, distilled into one clean tool.

🎯

Click tracking

Nanoid click IDs, cost per click/mile/action, sub1-sub5 passthrough, full macro support in offer URLs.

🛡

Smart cloaker

Blocks crawlers, datacenter ASNs, bad UAs, headless browsers, wrong geo — 11 signals out of the box.

🌎

Geo targeting

Allow/block countries via Cloudflare or custom headers. Per-campaign rules.

📄

White + prelanders

Drop HTML files in /landings. Use {{goUrl}}, {{clickid}} macros.

🔌

S2S postback

Server-to-server conversion tracking compatible with any affiliate network.

📊

Live dashboard

KPIs, timeline chart, per-campaign breakdown and real-time click feed with auto-refresh.

⚙

Zero config

SQLite file, no Redis, no Docker. Runs on a $5 VPS handling millions of clicks.

🔥

Fast redirects

~5ms overhead per click with prepared statements and WAL journaling.

📧

JS pixel ping

Landing pages can fire engagement pings so you can filter out non-browsers post-click.

Get started in 30 seconds

Run the following and open the dashboard.

git clone <this-repo> adtrack
cd adtrack
npm install
npm run seed        # creates a demo campaign
npm start           # open http://localhost:3000

Then test the tracker: /t/demo · Open /admin (token admin)
