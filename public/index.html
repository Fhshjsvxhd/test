Questions Вопросы

Does it really work out of the box? Оно правда работает из коробки?
Yes. One curl command installs everything, creates a token, starts the service on port 80, registers autostart. Open /admin, make a flow, done. Да. Одна команда curl ставит всё, создаёт токен, запускает сервис на порту 80, регистрирует автозапуск. Открываете /admin, создаёте поток — готово.
Do I need a domain? Нужен ли домен?
No. Cloakly works on the server IP right after install. For a production flow, attach any domain later by pointing an A-record to the server and filling the "Custom domain" field on the flow. Нет. Cloakly работает по IP сервера сразу после установки. Для продакшена можно в любой момент привязать домен, просто направив A-запись на сервер и заполнив поле "Свой домен" в потоке.
How good is the bot detection? Насколько хороша детекция ботов?
11+ signals: known crawler UAs, datacenter IP ranges (AWS/GCP/Azure/DO/OVH/Hetzner/Linode), VPN ASNs via Cloudflare headers, headless browsers, missing Accept-Language, JS challenge, referrer check, plus your own country/device/OS/browser filters and custom IP/UA blacklists. 11+ сигналов: известные UA краулеров, диапазоны IP дата-центров (AWS/GCP/Azure/DO/OVH/Hetzner/Linode), VPN ASN через заголовки Cloudflare, headless-браузеры, отсутствие Accept-Language, JS-проверка, referrer, плюс ваши фильтры по стране/устройству/ОС/браузеру и свои чёрные списки IP/UA.
What about HTTPS? А как с HTTPS?
Run sudo bash /opt/cloakly/install-https.sh your-domain.com email@you.com — it installs nginx + Let's Encrypt and switches Cloakly behind it. Запустите sudo bash /opt/cloakly/install-https.sh your-domain.com email@you.com — поставит nginx + Let's Encrypt и переключит Cloakly за nginx.
